⚙️ إعدادات النظام

🔐 حسابات الدخول والصلاحيات مرتبطة بالسحابة.
الحسابات الجديدة تُنشأ بدعوة من لوحة Supabase (Authentication ← Users ← Invite user)، وبعد قبول الدعوة يحدد المدير العام الصلاحية من قسم «إدارة مستخدمي النظام». كل حساب يرى بياناته فقط.
💾 النسخ الاحتياطي المحلي يبقى متاحًا كطبقة أمان إضافية. استخدم التصدير بانتظام، خصوصًا قبل أي تحديث كبير.

👑 إدارة مستخدمي النظام

إدارة حسابات Supabase وصلاحياتها
إضافة موظف: من لوحة Supabase ← Authentication ← Users ← «Invite user». بعد أن يفتح الموظف رابط الدعوة ويضع كلمة مروره يظهر هنا، ومن هنا تُحدد الصلاحية: موظف، مدير، أو مدير عام. الصلاحية تتحكم بما يظهر له فقط؛ ولا يستطيع أي حساب رؤية بيانات حساب آخر.

⚙️ الإعدادات والنسخ الاحتياطي

💾 حماية بياناتك
صدّر نسخة JSON قبل أي تعديل كبير، واستوردها لاحقًا لاسترجاع البيانات على نفس الموقع. النسخة الاحتياطية لا تُحفظ داخل الموقع حفاظًا على خصوصية بيانات العملاء.
الاستيراد لا يستبدل بياناتك إلا بعد ظهور رسالة تأكيد.
